# Liquid Motion アプリ設計と実装

Status: Implemented in PR #5  
Baseline: `main`  
Scope: 既存のCanvas 2Dと粒子物理を維持し、再現可能なシーン、状態管理、入力、配布、品質保証を追加する。

## 目的

Liquid Motionを、リセットのたびに配置が変わる物理デモから、同じシーンを上下反転して繰り返し遊べるデジタル鑑賞玩具へ発展させる。

## 実装した契約

### シーンと再現性

- `js/scenes.js`にJSON互換のシーン定義を追加
- `Step Drop`、`Gear Flow`、`Branch and Merge`の固定シーンを追加
- `Random Lab`をseed付き実験モードとして分離
- `js/random.js`にseed付き乱数を追加
- リセットは同じシーン・同じseedの初期状態へ戻す
- リサイズは粒子位置を再投影し、再スポーンしない
- URLに`scene`と`seed`を保存し、同じ状態を共有できる

### 状態機械と操作

`js/simulation.js`で次の状態を管理する。

- `ready`
- `running`
- `paused`
- `settled`
- `flipping`
- `resetting`
- `unsupported-input`

再生、一時停止、速度変更、反転、リセットは状態機械を経由する。反転中とリセット中は物理更新を止め、操作の競合を防ぐ。

### 反転と入力

- 600msの180度反転アニメーションを追加
- `prefers-reduced-motion`では反転演出を即時完了
- センサー、ボタン、ダブルタップ、キーボードを同じ反転コマンドへ統合
- センサー非対応・権限拒否時も手動操作を継続可能
- `touchmove`抑制をキャンバス内に限定

### 流体と機構

- 流体に`id`、色相、比重、粘度、凝集、粒子数、表示方式を定義
- 現行の粒子物理を視覚表現用の近似モデルとして維持
- 歯車リンクに回転比、方向、結合率を定義
- 接触量を蓄積して開く弁を追加
- 分岐・合流は固定シーンの幾何形状として定義

### PWA・保存・共有

- `manifest.webmanifest`と`sw.js`を追加
- 固定アセットをキャッシュし、オフラインで再生可能
- 選択シーンを`localStorage`へ保存
- 共有URL生成とJSONエクスポートを追加
- Canvas非対応時の代替メッセージを追加

### アクセシビリティ

- キーボード操作とフォーカス表示を追加
- 操作状態を`aria-live`で通知
- ボタンに視覚ラベルとツールチップを追加
- 色だけで状態を表さず、弁の開閉を形状変化でも示す
- モーション軽減設定に対応

### テストと性能確認

- seedの再現性
- 固定シーンの点対称性
- 一時停止と反転の状態遷移
- リセットで初期状態へ戻ること
- リサイズで粒子を再生成しないこと
- 歯車リンクの方向
- JavaScript構文確認

実行時には平均フレーム時間、粒子数、状態、シーンを`window.__liquidMotionMetrics`へ公開する。
